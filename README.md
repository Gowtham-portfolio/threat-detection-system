# 🔐 Threat Detection System (Real-Time)

A real-time camera-based threat detection system designed to monitor environments, detect suspicious activity, alert users instantly, and record evidence for security purposes.

---

## 📖 Project Overview

This project is a **real-time threat detection and alert system** built using live camera input.  
It continuously monitors video feeds, detects potential threats, and responds immediately by triggering alerts, capturing evidence, and notifying the system owner.

The system is suitable for **security surveillance**, **home safety**, **office monitoring**, and **restricted-area protection**.

---

## 🚨 Real-Time Alert Features

- Live camera monitoring with continuous detection
- Automatic beep alert on threat detection
- Captures photos and short video clips as evidence
- Sends instant notifications to the system owner
- Stores detected threat data for later review


---

## 🛠️ Technologies Used

- Python
- OpenCV (Computer Vision)
- Camera / Webcam Integration
- Automation & Alert Logic
- File Handling for Evidence Storage

---

## ⚙️ How the System Works

1. Live camera feed is continuously monitored  
2. System analyzes frames in real time  
3. When a threat is detected:
   - Alarm sound is triggered  
   - Image and video evidence is captured  
   - Notification/message is sent to the owner  
4. Evidence is stored securely for review  

---

## 🎯 Use Cases

## 🧠 System Architecture (High Level)

The system uses a live camera feed to continuously monitor the environment.  
When suspicious movement or predefined threat patterns are detected, the system immediately triggers alerts and evidence capture.

**Flow:**
Camera → Video Processing → Threat Detection Logic → Alert System → Evidence Storage → Owner Notification

---

## 📊 Output & Evidence Handling

- Captures **images** automatically when a threat is detected  
- Records **video clips** for evidence  
- Triggers **audio alerts (beep/alarm)** in real time  
- Stores evidence securely for later review
